# 🤖 Agentic AI Global Financial Stream Engine

Welcome to the **Agentic AI Global Financial Stream Engine** repository! This production-grade application combines real-time streaming, quantitative trading technical indicators, real-time sentiment scoring, and a context-aware conversational chat layout.

The engine utilizes an event-driven **Apache Kafka (Confluent)** distributed messaging framework to process live market tickers and news feeds asynchronously across global exchanges.

---

## 🚀 Key Production Features

1. **Persistent State Management & Cache Pinning**: Built-in caching hooks retain charts, tickers, indicators, and analytical grids securely on screen during concurrent conversational chat interaction reruns.
2. **14-Day RSI Technical Momentum Engine**: Calculates a rule-based Relative Strength Index (RSI) matrix to inject automated warning alerts if an asset enters **Overbought (>70)** or **Oversold (<30)** zones.
3. **Quantitative Volatility Floor Grid**: Dynamically computes floor trader Pivot Points (**R1, R2, S1, S2**) on the fly to establish real-time support and resistance levels.
4. **Live Streaming Sentiment Analysis Pipeline**: Parses real-time news headlines, scoring textual parameters from `-1.0 (Highly Bearish)` to `+1.0 (Highly Bullish)` using a dedicated financial lexicon.
5. **AI Signal Divergence Guardrails**: Triggers automated risk alerts if market chart trend momentum conflicts with real-time media sentiment scores (protecting capital from distribution traps).
6. **Corporate Action Translators**: Safely handles corporate action dataframes, checking data schemas to prevent execution errors on non-split assets (like `HFCL.NS`) and translates `2.0` split multipliers cleanly as **1:1 Bonus Share Issues** for Indian listings.
